# Portafolio digital — Sistemas Distribuidos

Este repositorio reúne el portafolio digital de la asignatura **Sistemas Distribuidos**. Su propósito es organizar las prácticas, proyectos, código fuente y documentación desarrollados durante las tres unidades de la materia.

Cada actividad cuenta con su propia carpeta y documentación. Las instrucciones específicas de instalación, configuración y ejecución se encuentran en el README de la actividad correspondiente.

## Unidad 1

### APE6 — Mensajería distribuida con MQTT y RabbitMQ

Proyecto de monitoreo de una flota vehicular mediante sensores simulados que publican datos de ubicación GPS, temperatura y nivel de combustible utilizando MQTT. Un servicio puente en Python conecta esta mensajería con RabbitMQ, mientras una aplicación Spring Boot contiene consumidores para procesar los mensajes, reenviar alertas a una cola de notificaciones y exponer una API REST de consulta con respuestas de ejemplo.

La práctica aborda la comunicación asíncrona, la organización jerárquica de topics MQTT y la configuración de exchanges, colas y bindings en RabbitMQ. La ejecución distribuida contempla una computadora como servidor y otros equipos conectados mediante su dirección IP.

- **Código fuente y archivos del proyecto:** [Unidad 1/APE6](<Unidad 1/APE6/>)
- **Instrucciones de descarga, configuración y ejecución:** [README de APE6](<Unidad 1/APE6/README.md>)

Antes de ejecutar la práctica, consultar su README para instalar las dependencias, ajustar las direcciones IP a la red utilizada y seguir el orden de inicio de los componentes.
